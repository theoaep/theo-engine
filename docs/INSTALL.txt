TheoEngine - install help (Windows + After Effects)
======================================================

EASY WAY — WINDOWS FILE COPY INSTALLER
--------------------------------------
1. Right-click INSTALL THEOENGINE.bat.
2. Choose "Run as administrator" and approve the Windows prompt.
3. The installer copies only the extension files to:
     %APPDATA%\Adobe\CEP\extensions\com.theo.engine
4. It does not change the registry or download software.
5. Restart After Effects and open Window > Extensions > TheoEngine.

If After Effects does not show an unsigned CEP extension, follow Adobe’s
manual CEP/PlayerDebugMode setup for your installed version. Windows
SmartScreen warnings cannot be safely removed by changing script format;
verify downloads came from https://github.com/theoaep/theo-engine/releases.

EASY WAY — MAC FILE COPY INSTALLER
----------------------------------
1. Open Terminal in the TheoEngine folder.
2. Run:
     chmod +x "INSTALL THEOENGINE.command" "UNINSTALL THEOENGINE.command" installer/*.sh
3. Double-click INSTALL THEOENGINE.command, or run it from Terminal.
4. Restart After Effects and open Window > Extensions > TheoEngine.

Mac CEP support and unsigned-extension behavior vary by Adobe version. The
Mac installer only copies to ~/Library/Application Support/Adobe/CEP/extensions/com.theo.engine.


WHAT THE INSTALLER CHANGES
--------------------------
- Copies only the contents of the extension folder to:
    %APPDATA%\Adobe\CEP\extensions\com.theo.engine
- Uses preservation mode: destination-only files are not deleted.
- Sets PlayerDebugMode=1 under these current-user registry keys:
    HKEY_CURRENT_USER\Software\Adobe\CSXS.9
    HKEY_CURRENT_USER\Software\Adobe\CSXS.10
    HKEY_CURRENT_USER\Software\Adobe\CSXS.11
    HKEY_CURRENT_USER\Software\Adobe\CSXS.12
- Does not install a browser, download external software, or clear user data.


MANUAL EXTENSION INSTALL
------------------------
1. Copy the contents of the extension folder into a folder named:
     com.theo.engine

   Destination:
     %APPDATA%\Adobe\CEP\extensions\com.theo.engine

2. Enable PlayerDebugMode=1 for the applicable Adobe CSXS registry version.
3. Fully restart After Effects.
4. Open Window > Extensions > TheoEngine.


UPDATING
--------
Double-click INSTALL THEOENGINE.bat again. It updates the installed panel
without deleting destination-only files or browser/localStorage user data.


UNINSTALL
---------
Delete the com.theo.engine folder from:
  %APPDATA%\Adobe\CEP\extensions
