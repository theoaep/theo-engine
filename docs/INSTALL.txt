TheoEngine - install help (Windows + After Effects)
======================================================

EASY WAY
--------
1. Go to the main TheoEngine folder.
2. Double-click:
     INSTALL THEOENGINE.bat
3. If Windows SmartScreen appears, verify the package came from:
     https://github.com/theoaep/theo-engine/releases
   Choose More info > Run anyway only if you trust the verified package.
   The installer is unsigned, so SmartScreen may still display a warning.
4. The branded installer asks:
     Install TheoEngine for After Effects? [Y/N]
5. Choose Y to install the panel. It enables Adobe CEP PlayerDebugMode
   for CSXS 9-12 because this is an unsigned CEP extension.
6. Fully restart After Effects and open:
     Window > Extensions > TheoEngine

Keep the complete downloaded folder together. The launcher needs both the
installer and extension folders beside it. No browser or external software is
installed.


WHAT THE INSTALLER CHANGES
--------------------------
- Copies only the contents of the extension folder to:
    %APPDATA%\Adobe\CEP\extensions\com.theo.engine
- Uses preservation mode: destination-only files are not deleted.
- Sets PlayerDebugMode=1 under these current-user registry keys:
    HKEY_CURRENT_USER\Software\Adobe\CSXS.9
    HKEY_CURRENT_USER\Software\Adobe\CSXS.10
    HKEY_CURRENT_USER\Software\Adobe\CSXS.11
    HKEY_CURRENT_USER\Software\Adobe\CSXS.12
- Does not install a browser, download external software, or clear user data.


MANUAL EXTENSION INSTALL
------------------------
1. Copy the contents of the extension folder into a folder named:
     com.theo.engine

   Destination:
     %APPDATA%\Adobe\CEP\extensions\com.theo.engine

2. Enable PlayerDebugMode=1 for the applicable Adobe CSXS registry version.
3. Fully restart After Effects.
4. Open Window > Extensions > TheoEngine.


UPDATING
--------
Double-click INSTALL THEOENGINE.bat again. It updates the installed panel
without deleting destination-only files or browser/localStorage user data.


UNINSTALL
---------
Delete the com.theo.engine folder from:
  %APPDATA%\Adobe\CEP\extensions
